Duelio Game Index

Developer: METK LLC

Every title below is native software bundled in the Duelio iOS app and iMessage extension. These links open the selected built-in game in Duelio when the app is installed, and this page remains available as the web index. Duelio does not offer HTML5, JavaScript, streaming, downloaded, or third-party games.

Not currently available

Party Games, Side Racer, and Hangman are shown as Coming Soon and cannot be opened in the submitted build. Party Games’ internal round prototypes are therefore not available software. Spades is retained only so older game messages remain decodable and is not shown in the public catalog. Table Builder and Board Builder are configuration tools for the existing Pool and Word Games titles, not separate games or software.

Network services

api.duelioapp.com provides room coordination, multiplayer synchronization, social features, and player reports. It does not deliver executable code, game files, game assets, or new game functionality.

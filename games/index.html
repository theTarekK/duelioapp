Duelio Game Index

Developer: METK LLC

The current iOS 1.3 catalog contains 29 native titles developed by METK LLC: 26 in the standalone app and 3 additional titles in the iMessage extension. Gameplay code, UI, and built-in game assets ship with the app. Duelio does not download, stream, or execute remote game code and includes no HTML5/JavaScript mini-games, chatbots, plug-ins, emulators, or third-party game titles.

Quick Draw

Quick Draw is a native timed drawing game. A Core ML recognition model bundled with the app guesses drawings on the device. It is not a chatbot, remotely hosted AI game, or separately downloaded title. Shared drawing galleries are player-created match data.

Not in the current catalog

Ring Toss, Archery, and Spinblade are hidden from catalog launchers; their registrations remain for existing sessions. Party Games, Spades, Side Racer, and Hangman are unavailable and excluded from the current public catalog.

Table Builder and Board Builder configure the existing native Pool and Word Games titles. They are tools, not additional game titles.

Network services

api.duelioapp.com coordinates multiplayer rooms, synchronization, social features, purchases, gifting, player reports, and shared match data such as drawing galleries. It does not deliver executable game code or additional games.

Review access

No account, login, or credentials are required. Open Duelio to browse the standalone catalog. For online multiplayer, use Host Online on device A and Join with Code on device B. Open the Duelio extension in a Messages conversation for iMessage play; Insider and 2 Truths & 1 Lie need at least three participants.

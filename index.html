Online matchmaking

Nobody in the chat? Play the world.

Every game hosts and matches online. No friends required, and no account either. You are an anonymous device ID and a display name, nothing more.

HOST ONLINE

Set the game up, then open a public room. Hosting mints a short room code and puts your table on that game's queue so seekers get routed straight in. Flip it Public or Private any time.

FIND A GAME

Search for an open room someone is hosting. It joins the moment someone hosts that game and mode. No lobby browser, no ready-up ceremony with strangers.

JOIN WITH CODE

Got a code from a friend? Type it to drop into their exact room. A mistyped code just reads as no open room, never a silent empty lobby.

Anonymous by default

No sign in, no login, no email. Just a random per-install ID that resets if you reinstall.

Matched on what matters

Pools split by game, mode and language, never by difficulty or timer, so the pool stays big enough to actually pair.

1v1 duels and live rooms

Turn based games run 1v1 over a relay. Live party and card games seat a whole room, filling one seeker at a time.

Same game, three doors

An invite bubble, a room code and the matchmaker are three ways for two devices to agree on one room. The game can't tell them apart.

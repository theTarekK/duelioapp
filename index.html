Online matchmaking

Nobody in the chat? Play the world.

Every game hosts and matches online — no friends required, no account either. You’re an anonymous device ID and a display name, nothing more.

📡

HOST ONLINE

Set the game up, then open a public room. Hosting mints a short room code and puts your table on that game’s queue so seekers get routed straight in. Flip it Public ⇄ Private any time.

🔍

FIND A GAME

Search for an open room someone’s hosting. It joins the moment someone hosts that game and mode — no lobby browser, no ready-up ceremony with strangers.

🔑

JOIN WITH CODE

Got a code from a friend? Type it to drop into their exact room. It’s a friends feature — a mistyped code just reads “no open room,” never a silent empty lobby.

STRATEGY · SPORTS

The fine print, unfined

We built Duelio to need as little of your data as possible.

  • No third-party software — zero ads, analytics or trackers
  • No accounts, no passwords, no permissions requested
  • Your stats and unlocks never leave your device
  • Turn-based games ride iMessage — we never see them

One honest caveat: live and online matches connect to a Duelio server and are not end-to-end encrypted. We say so plainly, in plain English.
